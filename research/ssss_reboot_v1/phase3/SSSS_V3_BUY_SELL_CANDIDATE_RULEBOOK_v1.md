# 6. 浅灰带全组合扫描的 QA 注意事项

本轮 L1-L7 扫描出现多组：

- `...|ABOVE` + LIGHT_SUPPORT = 100%
- `...|BELOW` + LIGHT_RESIST = 100%

这些结果 **不得作为新交易规则**。

原因：

- LIGHT_SUPPORT 的 HOLD 判定允许从事件 bar 当天收盘开始；
- 如果组合又条件化为 `close_zone=ABOVE`，那么该 bar 本身已经满足“收回 GZB3 上方”；
- 同理 `close_zone=BELOW` 对 LIGHT_RESIST 也是机械成立。

因此这种 100% 是**条件定义与结果定义重叠造成的结构性必然**，不是预测优势。

处理：
- 从候选交易规则中剔除这些 100% 组合；
- 保留没有用 event close-zone 自我定义结果的预设浅灰带规则，例如 BUY-B / BUY-C / SELL-A；
- 下一轮如继续扫描浅灰带细分，结果窗口应从 t+1 开始，避免同 bar 自确认。
