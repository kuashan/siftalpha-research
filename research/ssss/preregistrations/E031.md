# E031 Pre-registration — Structural Confirmation ADD

Date: 2026-09-19
Status: PRE-REGISTERED
Category: ADD research

## Research question

Can the relative separation of the SSSS fast band from the slow white band identify an intermediate confirmation point that occurs after Qualified GRB but before Effective Red, and that supports a positive ADD leg without simply chasing price progress?

E031 is materially different from E030.

E030 required:
- favorable price progress
- a specific pullback
- a later re-acceleration
- an anti-chase cap

E031 does not require a pullback or a prior ATR-profit threshold. It tests the structural separation of the two model bands directly.

## Baseline trade definition

OPEN:
Qualified GRB, signal at close, execute next tradable open.

Official CLOSE:
- Failure path: Effective Gray -> Effective Green, execute next open.
- Mature path: Effective Red -> Effective Gray, execute next open.

Transaction cost:
0.1% per side.

Only one E031 ADD event may be counted per original trade per variant.

ADD signal is known at close and executes at the next tradable open.

ADD-leg return is measured from ADD execution open through the official final CLOSE execution open, charging 0.1% on ADD entry and 0.1% on ADD exit.

## Structural variable

Define:

```text
StructuralSep = (FastMid - WhiteMid) / WhiteWidth
```

where:

```text
WhiteWidth = WhiteUpper - WhiteLower
```

A candidate structural crossing occurs when StructuralSep crosses upward through its fixed threshold:

```text
StructuralSep[t] > threshold
AND
StructuralSep[t-1] <= threshold
```

The crossing must occur:
- after the original Qualified GRB OPEN execution;
- before the first Effective Red confirmation;
- before any official CLOSE signal.

If StructuralSep is already above a threshold before the original OPEN execution and never recrosses it later, that threshold does not generate an E031 ADD event for that trade.

## Fixed six-variant Discovery family

Three structural thresholds:

- S050: StructuralSep crosses above 0.50
- S100: StructuralSep crosses above 1.00
- S150: StructuralSep crosses above 1.50

Two confirmation modes:

### B — Base structural confirmation

On the structural crossing bar:

- dsep > 0
- C >= FastMid
- EffectiveState != RED

### X — Strong price confirmation

On the structural crossing bar:

- dsep > 0
- C > FastUpper
- EffectiveState != RED

The six variants are:

## Discovery metrics

For every variant report:

- total signals
- resolved ADD legs
- unresolved ADD legs
- number of stocks producing signals
- ADD-leg win rate
- average net ADD-leg return
- median net ADD-leg return
- 25th percentile
- worst ADD-leg return
- profit factor
- median ADD execution distance from original entry in EntryATR units
- 75th-percentile ADD execution distance from original entry in EntryATR units
- median trading bars from original entry to ADD
- for trades that later reach Effective Red: median bars from ADD signal to first Effective Red
- Mature-path / Failure-path distribution
- top-3 winning ADD legs as a share of gross positive ADD return

EntryATR = ATR14 on the original Qualified GRB signal bar.

## Discovery eligibility

A variant may advance to OOS only if all are true:

- at least 15 resolved ADD legs;
- signals occur in at least 8 Discovery stocks;
- average net ADD-leg return > 0;
- median net ADD-leg return > 0;
- profit factor > 1.25;
- 25th percentile net ADD-leg return > -8%;
- top-3 winners contribute no more than 70% of gross positive ADD return;
- median ADD execution distance <= 2.5 EntryATR;
- among later-Mature trades with a defined first Effective Red, median lead time from ADD signal to Effective Red >= 2 trading bars.

Among eligible variants, freeze exactly one using:

1. highest median net ADD-leg return;
2. if medians are within 0.25 percentage points, higher profit factor;
3. if still tied, larger resolved event count.

If no variant meets all criteria, E031 stops after Discovery and OOS remains unopened.

## OOS pass rule

Before OOS is queried, the single selected Discovery rule and exact formula must be committed to main.

OOS passes only if:

- at least 6 resolved ADD legs;
- signals occur in at least 4 OOS stocks;
- average net ADD-leg return > 0;
- median net ADD-leg return > 0;
- profit factor > 1.0.

If fewer than 6 resolved ADD legs occur, classify OOS as INCONCLUSIVE.

No rule or threshold may be changed under E031 after OOS is viewed.

## Frozen OOS rule

Frozen OOS remains unopened unless OOS passes.

Before Frozen OOS is queried, the exact surviving rule must already be committed.

Interpretation:

- >= 3 resolved events and mean > 0 and median > 0: SUPPORTIVE
- >= 3 resolved events and either mean <= 0 or median <= 0: FAIL
- < 3 resolved events: INCONCLUSIVE

Frozen OOS may not be used to retune E031.
