# E030 Pre-registration — Progress → Controlled Pullback → Re-acceleration ADD

Date: 2026-09-19  
Status: PRE-REGISTERED  
Category: ADD research

## Research question

Can SSSS add exposure after an early Qualified GRB trade has already demonstrated favorable progress, then completed a controlled pullback, and then re-accelerated — while still entering materially earlier than Effective Red and avoiding the chase behavior seen in simple +1 ATR / +2 ATR / Red-confirmed ADD rules?

This round is specifically designed to search for an intermediate ADD zone between:

- Qualified GRB: early but uncertain
- Effective Red: more confirmed but too late

## Baseline trade definition

OPEN:
Qualified GRB, signal at close, execute next tradable open.

Official CLOSE:
- Failure path: Effective Gray -> Effective Green, execute next open.
- Mature path: Effective Red -> Effective Gray, execute next open.

Transaction cost:
0.1% per side.

Only one E030 ADD event may be counted per original trade.

ADD signal is known at close and executes at the next tradable open.

ADD-leg return is measured from ADD execution open through the official final CLOSE execution open, with 0.1% cost on ADD entry and 0.1% cost on ADD exit.

## Discovery candidate family

This is a bounded six-variant Discovery family, not an open-ended threshold search.

All variants require:

1. An active Qualified GRB trade.
2. The E030 ADD must occur before the trade's first Effective Red confirmation.
3. Favorable progress must occur before the pullback.
4. A qualifying pullback must occur after progress.
5. Re-acceleration must occur after the pullback and within 10 trading bars.
6. Before ADD signal:
   - no official CLOSE has fired;
   - Effective State is not Red.
7. Re-acceleration signal:
   - C > FastUpper
   - C > REF(H,1)
   - dsep > 0
   - C <= prior_running_high + 0.25 * EntryATR
8. Execute ADD next open.

EntryATR = ATR14 on the original Qualified GRB signal bar.

prior_running_high = highest H from original OPEN execution bar through the pullback bar.

### Progress thresholds

Exactly three thresholds will be tested:

- P075: prior running MFE >= 0.75 * EntryATR
- P100: prior running MFE >= 1.00 * EntryATR
- P150: prior running MFE >= 1.50 * EntryATR

Progress is only a prerequisite. This round does not test direct ADD at those thresholds.

### Controlled-pullback structures

Exactly two structures will be tested.

#### U — FastUpper reset

After progress, a pullback bar must satisfy:

- FastMid <= C <= FastUpper
- Effective State != Red
- C >= WhiteLower - 1 * ATR14

#### M — FastMid test/reclaim

After progress, a pullback bar must satisfy:

- L <= FastMid
- C >= FastMid
- C <= FastUpper
- Effective State != Red
- C >= WhiteLower - 1 * ATR14

The six Discovery variants are therefore:

- E030-U075
- E030-U100
- E030-U150
- E030-M075
- E030-M100
- E030-M150

No seventh variant may be added under E030 after Discovery outcomes are viewed.

## Discovery evaluation

For every variant report:

- total signals
- resolved ADD legs
- unresolved ADD legs
- number of stocks producing signals
- ADD-leg win rate
- average net ADD-leg return
- median net ADD-leg return
- 25th percentile
- worst ADD-leg return
- profit factor
- average ADD execution distance from original entry in EntryATR units
- average ADD execution distance from prior running high in EntryATR units
- Mature-path / Failure-path distribution
- contribution of top 3 winning ADD legs to gross positive ADD return

### Discovery eligibility for freezing

A variant may advance to OOS only if all are true:

- at least 12 resolved ADD legs;
- signals occur in at least 6 Discovery stocks;
- average net ADD-leg return > 0;
- median net ADD-leg return > 0;
- profit factor > 1.0.

Among eligible variants, freeze exactly one rule using this ranking:

1. highest median net ADD-leg return;
2. if tied within 0.25 percentage points, higher average net ADD-leg return;
3. if still tied, larger resolved event count.

If no variant meets all eligibility criteria, E030 stops after Discovery and is rejected without opening OOS.

## OOS rule

Before OOS is queried, the selected single variant and its exact formula must be committed to main.

OOS passes only if:

- at least 5 resolved ADD legs;
- signals occur in at least 3 OOS stocks;
- average net ADD-leg return > 0;
- median net ADD-leg return > 0;
- profit factor > 1.0.

If fewer than 5 resolved events occur, classify OOS as INCONCLUSIVE, not PASS.

No threshold or formula may be changed after OOS is viewed under E030.

## Frozen OOS rule

Frozen OOS remains unopened unless OOS passes.

Before Frozen OOS is queried, the exact surviving rule must already be committed.

Frozen OOS interpretation:

- >= 3 resolved events and both mean and median > 0: supportive;
- >= 3 resolved events and either mean or median <= 0: fails Frozen OOS;
- < 3 resolved events: INCONCLUSIVE due insufficient event count.

Frozen OOS is not allowed to trigger rule retuning under E030.
