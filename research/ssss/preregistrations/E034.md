## Official SSSS lifecycle

OPEN signal:
Qualified GRB at decision-bar close:
- EffectiveState = GREEN
- H > FastUpper
- REF(H,1) <= REF(FastUpper,1)
- dsep > 0
- C >= WhiteLower - 2 * ATR14

Execute next bar open.

Failure:
before any Effective Red:
Effective Gray -> Effective Green,
execute next bar open.

Mature:
after Effective Red maturity:
Effective Red -> Effective Gray,
execute next bar open.

## Fixed feature definitions

### ER10

Kaufman-style 10-bar efficiency ratio:

ER10 =
abs(C[t] - C[t-10])
/
sum(abs(C[i] - C[i-1]), i=t-9..t)

If denominator = 0:
feature is missing.

Range:
0 to 1.

### CHOP14

TR[i] =
max(
H[i]-L[i],
abs(H[i]-C[i-1]),
abs(L[i]-C[i-1])
)

CHOP14 =
100
*
log10(sum(TR,14) / (HH14 - LL14))
/
log10(14)

If HH14 - LL14 <= 0:
feature is missing.

Do not apply textbook 38.2 / 61.8 thresholds in E034.

### CMF20

MoneyFlowMultiplier =
((C-L) - (H-C)) / (H-L)
=
(2*C-H-L)/(H-L)

If H=L:
MoneyFlowMultiplier = 0 for that bar.

MoneyFlowVolume =
MoneyFlowMultiplier * Volume

CMF20 =
sum(MoneyFlowVolume,20)
/
sum(Volume,20)

If 20-bar volume sum <= 0:
feature is missing.

### OBVImpulse10

To avoid arbitrary OBV starting-level dependence:

SignedVolume[i] =
sign(C[i] - C[i-1]) * Volume[i]

with sign = +1 / 0 / -1.

OBVImpulse10 =
sum(SignedVolume,10)
/
sum(Volume,10)

If 10-bar volume sum <= 0:
feature is missing.

This is equivalent to normalized 10-bar OBV change, not raw OBV level.

## Fixed diagnostic metrics

For each track, snapshot, and feature:

- resolved event count
- Mature count
- Failure count
- feature mean by path
- feature median by path
- Mature-minus-Failure median difference
- Cliff's delta, defined positive when Mature values tend to exceed Failure values
- Q1 / Q2 / Q3 / Q4 counts using pooled Discovery quartiles for that feature/snapshot
- Mature rate by quartile
- median official final return by quartile
- missing-value count

No threshold search.

No optimized cutoff.

## Equity diagnostic-candidate gate

A feature/snapshot becomes an E034 EQUITY_DIAGNOSTIC_CANDIDATE only if:

- at least 30 resolved events;
- at least 8 Failure events;
- absolute Cliff's delta >= 0.33;
- Mature-vs-Failure medians have the same direction as Cliff's delta;
- extreme-quartile Mature-rate spread is at least 20 percentage points in the same direction;
- each extreme quartile contains at least 7 events.

This does NOT validate a trading rule.

## Cross-asset interpretation

Do not average equity and crypto metrics.

A feature may be called CROSS_ASSET_CANDIDATE only if:
- it passes the equity diagnostic gate; and
- crypto has at least 12 resolved events with at least 3 Failure events; and
- crypto Cliff's-delta sign matches equity; and
- absolute crypto Cliff's delta >= 0.20.

This remains diagnostic only.
