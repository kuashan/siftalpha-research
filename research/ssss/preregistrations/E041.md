## 6. Fixed LOSS_PULLBACK_ADD rule

No threshold search is allowed in E041.

Local anchor:
- initialize at Starter OPEN execution price
- on each completed bar: local_anchor = max(local_anchor, completed bar high)
- pullback PB = close / local_anchor - 1

A LOSS_PULLBACK_ADD signal occurs only on the first completed bar where:

- PB <= -1%
- close >= FastLower
- EffectiveState in {GREEN, RED}
- dsep > 0
- weighted current position return at signal close < 0
- variant still has remaining ADD capacity
- cooldown is clear

Execution:
- next 15m open
- +10 percentage points account exposure
- base friction charged exactly as E040
- stress friction charged exactly as E040

After an executed ADD:
- local_anchor resets to that ADD execution price
- cooldown = 4 completed 15m bars
- then local_anchor resumes tracking completed-bar highs

FastLower validity-break / reclaim handling is inherited explicitly from E040:

- if a completed bar closes below FastLower, no new ADD is allowed;
- while below FastLower, the ladder is inactive;
- on the first completed bar that causally reclaims FastLower, set local_anchor to that reclaim bar's completed high;
- the reclaim bar itself cannot create an ADD;
- a fresh later 1% pullback from the reset local_anchor is required before another ADD can occur.

No TREND_PULLBACK_ADD.
No REDUCE.
No RE-ADD.
No new CLOSE.
