## 6. Base second LOSS_ADD trigger

After the first ADD and cooldown, the unfiltered second signal is exactly the E041 second LOSS_ADD:

- fresh local pullback <= -1%
- FastLower validity intact / causal reclaim semantics unchanged
- EffectiveState in {GREEN, RED}
- dsep > 0
- weighted position return < 0
- next-open execution
- +10pp
- 40% -> 50%

E042 changes only whether this second signal is ADMITTED.

Only the FIRST base second-LOSS_ADD signal in each lifecycle is evaluated.

If that first base second signal is rejected by a candidate:
- exposure remains at 40%;
- no later second-ADD attempt is allowed in that lifecycle;
- later pullbacks are ignored until reference CLOSE.

This prevents repeated retries from silently changing the admission problem.

### C4_FASTLOWER_BUFFER_05ATR

### C5_POST_FIRST_ADD_MAE_LE_1ATR

At the first ADD signal, freeze ATR_first_add = ATR(signal bar).

From first ADD execution through the second ADD signal bar, define:

PostFirstAddMAE =
(min completed-bar low - first ADD execution price) / ATR_first_add.

Admit second ADD only if:

PostFirstAddMAE >= -1.00 ATR.

This is a causal path-risk screen; it uses only bars already completed before the second ADD signal.

### C6_GREEN_AND_DSEP_ACCEL

- EffectiveState == GREEN

### C7_BUFFER_AND_MAE
