## 5. Local anchor mechanics

At starter execution:
local_anchor = starter execution price.

For each completed 15m bar:
local_anchor = max(local_anchor, completed-bar high).

Pullback at bar t:

PB(t) = close(t) / local_anchor - 1.

A ladder event occurs on the first bar where:

PB(t) <= -D.

Action executes next 15m open.

After ANY ladder ADD or REDUCE:
local_anchor resets to that next-open execution price.

From then on:
local_anchor again updates with future completed-bar highs.

Therefore:
- continued decline can trigger another D% step from the previous action level;
- a recovery/new high followed by another D% pullback can also trigger again.

Minimum cooldown:
4 bars after each ladder action.

## 8. Repeated ADD

At a D% pullback event:

If:
- CONTINUATION_STRONG
- exposure < 50%

then:
ADD +10 percentage points account exposure next open.

The action is classified after the fact for reporting:

- TREND_PULLBACK_ADD if weighted position return at signal close >= 0
- LOSS_PULLBACK_ADD if weighted position return < 0

Maximum exposure:
50%.

With a 30% starter this permits at most two active +10pp additions before intervening reductions.

## 9. Repeated REDUCE

At a D% pullback event:

If:
- RISK_BUT_VALID
- weighted position return > 0
- current exposure > 30%

then:
sell 15% of CURRENT POSITION QUANTITY next open.

Do not reduce below the 30% core exposure floor.

This action may repeat after the local anchor resets and a new D% pullback occurs.

## 10. No action after validity break

If the structural floor is broken:

- no new ADD
- no new REDUCE

until either:
- the reference CLOSE occurs, or
- the floor is causally reclaimed and a new local anchor begins.

Reclaim does not itself create an ADD.
A fresh D% pullback after reclaim is still required.
