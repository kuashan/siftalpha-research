# E033 Pre-registration — Selective Early Second Entry

Date: 2026-09-19
Status: PRE-REGISTERED
Category: ADD / position-sizing research

## Research question

After a validated Qualified GRB OPEN, can one additional unit be deployed selectively during the early lifecycle using genuinely new post-entry information, while avoiding a meaningful share of failure-path trades?

E033 is motivated by E032 but does not reuse E032 as validation.

E032 showed that marginal ADD economics were strongest early and near the original entry. E033 therefore tests exact causal early-entry rules.

## Baseline lifecycle

Original OPEN:
Qualified GRB signal at close, execute next tradable open.

Official CLOSE:
- Failure: Effective Gray -> Effective Green, execute next open before any Effective Red.
- Mature: after Effective Red maturity, Effective Red -> Effective Gray, execute next open.

Transaction cost:
0.1% per side.

Only one E033 second-unit ADD may occur per original trade.

ADD signal is known at close and executes next tradable open.

## Timing convention

Let the original OPEN execution bar be entry bar 0.

E033 decision bars may start on the close of entry bar 0.

Therefore:
- decision on entry bar 0
- second unit executes at next trading day's open

This guarantees that every E033 second-unit action uses at least one complete post-entry daily bar of new information.

No E033 second unit may execute on the same open as the original unit.

All E033 candidates must fire:
- before the official CLOSE signal;
- before first Effective Red confirmation;
- no later than their fixed early window.

## Fixed four-rule family

### E033-C04 — Early Continuation

First qualifying decision bar from entry bar 0 through bar 4:

- PRE_RED
- EffectiveState = GREEN
- dsep > 0
- 0 < CurrentProgressATR <= 1
- GivebackATR < 0.5

Interpretation:
the original trade remains structurally Green and has made modest progress without becoming extended.

### E033-D10 — Early Discount / Unproven Trend

First qualifying decision bar from entry bar 0 through bar 9:

- PRE_RED
- EffectiveState = GREEN
- dsep > 0
- CurrentProgressATR <= 0
- RunningMFEATR < 1
- StructuralSep < 0

Interpretation:
price has not proven itself yet, but the original bullish structure remains intact and the fast/slow structure has not become extended.

### E033-S10 — Structural Discount

First qualifying decision bar from entry bar 0 through bar 9:

- PRE_RED
- EffectiveState in {GREEN, GRAY}
- dsep > 0
- StructuralSep < 0
- C < FastMid

No CurrentProgressATR condition.

Interpretation:
a broader structural-discount entry inspired by the strongest E032 formal map cell.

### E033-R10 — Early Entry Reclaim

First qualifying decision bar from entry bar 1 through bar 9:

- PRE_RED
- EffectiveState = GREEN
- dsep > 0
- previous close <= original entry open
- current close > original entry open
- current close <= original entry open + 1 * EntryATR

Interpretation:
the trade first spent time at or below the original entry, then reclaimed the entry price while the bullish state remained intact.

## Benchmarks

E033 reports three reference policies.

### BASE_1U

The validated original one-unit trade only.

### IMMEDIATE_2U

Two equal units both entered at the original OPEN execution price and both exited at the official final CLOSE.

This is the benchmark for simply increasing starter size.

### NEXTDAY_2ND

One unit at original OPEN plus an unconditional second unit at the next tradable open after entry bar 0, provided the trade is still active.

This measures the economics of mechanically splitting the initial position by one day without selectivity.

These benchmarks are descriptive and are not candidate rules.

## Candidate metrics

For each candidate report:

- total triggered trades
- resolved ADD legs
- unresolved ADD legs
- unique stocks
- trigger rate across resolved baseline trades
- Mature-path trigger rate
- Failure-path trigger rate
- percentage of Failure trades that avoid a second unit
- ADD-leg win rate
- average ADD-leg net return
- median ADD-leg net return
- 25th percentile
- worst ADD-leg return
- profit factor
- top-3 winners as share of gross positive ADD return
- median execution distance from original entry in EntryATR
- median bars from original entry to ADD execution
- mean and median delay cost versus an immediate second unit on the same triggered trades

Define:

```text
delay_cost
=
delayed_second_unit_return
-
immediate_second_unit_return_for_same_trade
```

Also report portfolio-style incremental contribution:

```text
selective_second_unit_contribution
=
sum(second-unit net returns, using 0 for untriggered resolved trades)
/
number of resolved baseline trades
```

This is descriptive only because capital deployment differs across policies.

## Discovery eligibility

A candidate may advance only if all are true:

- at least 15 resolved ADD legs;
- at least 8 unique stocks;
- average ADD-leg net return > 0;
- median ADD-leg net return > 0;
- profit factor > 1.25;
- 25th percentile > -8%;
- top-3 winners <= 70% of gross positive ADD return;
- Mature-path trigger rate exceeds Failure-path trigger rate by at least 15 percentage points;
- at least 40% of resolved Failure trades avoid the second unit;
- median ADD execution distance <= 1.5 EntryATR.

A candidate is not rejected merely because waiting underperforms immediate entry on the same successful trade. Delay cost is reported separately because selectivity may compensate for timing cost.

## Discovery winner

Among eligible candidates freeze exactly one rule using:

1. highest median ADD-leg net return;
2. if medians differ by <= 0.25 percentage points, larger Mature-minus-Failure trigger-rate spread;
3. if still tied, higher profit factor;
4. if still tied, larger resolved ADD count.

Before OOS is queried, the exact selected rule must be committed to main.

If no candidate passes, E033 stops and OOS remains unopened.

## OOS pass rule

OOS passes only if:

- at least 6 resolved ADD legs;
- signals occur in at least 4 OOS stocks;
- average ADD-leg net return > 0;
- median ADD-leg net return > 0;
- profit factor > 1.0;
- Mature-path trigger rate is greater than Failure-path trigger rate.

If fewer than 6 resolved ADD legs occur:
INCONCLUSIVE.

No retuning is allowed after OOS is viewed.

## Frozen OOS rule

Frozen OOS remains unopened unless OOS passes.

Interpretation:
- >= 3 resolved ADD legs and mean > 0 and median > 0: SUPPORTIVE
- >= 3 and either mean <= 0 or median <= 0: FAIL
- < 3: INCONCLUSIVE

Frozen OOS may not be used to retune E033.

## Production rule

Even a SUPPORTIVE Frozen OOS result does not automatically change position sizing.

Before production adoption, the final candidate must also be compared against:
- BASE_1U
- IMMEDIATE_2U
- NEXTDAY_2ND

with explicit portfolio/risk sizing assumptions.
