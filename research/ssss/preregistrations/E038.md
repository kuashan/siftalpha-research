CORE 30%

It does not treat REDUCE as a permanent sale held to the final close.

## 2. Research question

Can a 10% tactical tranche be temporarily removed during deterioration and restored during recovery in a way that:

- improves the tactical tranche economics;
- reduces drawdown / giveback;
- preserves the 30% core position and large-trend participation;
- avoids unnecessary full closes?

Second question:

Can RE-ADD reuse the exact first-ADD rule, or does it require a different recovery rule?

## 5. Fixed position architecture

GREEN_TRANSITION
-> next 15m open
-> 30% core exposure.

First ADD:

RunningMFEATR < 1
AND CurrentProgressATR <= 0

Only lifecycles in which this first ADD actually executes are eligible for E038 tactical-tranche research.

## 6. REDUCE candidates

A REDUCE event can occur only after the 10% tactical ADD exists.

It sells the entire tactical 10% tranche next open, leaving the 30% core untouched.

Exactly three candidates:

### R1 — GREEN_TO_GRAY_AFTER_ADD

First Effective GREEN -> GRAY transition after tactical ADD.

Purpose:
state deterioration without thesis invalidation.

### R2 — POST_RED_MFE4_GIVEBACK05

First bar after Effective Red maturity where:

RunningMFEATR >= 4
AND GivebackATR >= 0.5

Purpose:
mature-trend giveback after meaningful favorable excursion.

### R3 — RTE_MFE2

First RTE event after tactical ADD where:

RunningMFEATR >= 2

RTE:
EffectiveState = RED
AND H > FastUpper
AND C >= O
AND FastWidth > REF(FastWidth,5)
AND dsep < 0

Purpose:
tactical exhaustion after sufficient prior progress.

No fourth REDUCE trigger may be added after results are seen.

## 7. RE-ADD candidates

After tactical REDUCE and before reference CLOSE, evaluate exactly four recovery rules.

RE-ADD restores the tactical tranche from 0% back to 10% next open.

### A0 — LITERAL_FIRST_ADD_REUSE

Use the exact original first-ADD condition again:

RunningMFEATR < 1
AND CurrentProgressATR <= 0

This explicitly tests whether the first ADD formula can literally be reused.

### A1 — GREEN_RECOVERY

First non-GREEN -> GREEN transition after REDUCE

AND re-add execution open <= reduction execution open + 1 EntryATR.

### A2 — DSEP_RECOVERY

First dsep transition:
<= 0 -> > 0

after REDUCE

AND re-add execution open <= reduction execution open + 1 EntryATR.

### A3 — FASTMID_RECOVERY

First close transition:
<= FastMid -> > FastMid

after REDUCE

AND re-add execution open <= reduction execution open + 1 EntryATR.

No additional recovery rule may be added after outcomes are viewed.

## 9. Tactical-tranche accounting

All metrics are calculated first on the 10% tactical tranche independently.

Baseline tactical return:
first-ADD execution
-> reference CLOSE.

For a paired variant:

first-ADD execution
-> REDUCE execution
plus, if RE-ADD occurs:
RE-ADD execution
-> reference CLOSE.

All entry/exit sides pay the fixed friction.

Incremental tactical value:

paired tactical PnL
minus
baseline tactical PnL.

Portfolio-equivalent value:

incremental tactical value * 10%.

This avoids confusing a 10% tactical decision with the 30% core economics.

## 10. Full-close comparison

At each REDUCE event also compute:

FULL_CLOSE_EDGE =
full-position next-open close proceeds
versus
reference final-close proceeds.

This is diagnostic only.

Interpretation:

- paired tactical value positive + full-close edge negative:
  evidence for REDUCE, not CLOSE;
- full-close edge persistently positive:
  possible future CLOSE research candidate;
- neither positive:
  HOLD remains superior.

E038 does not change the reference CLOSE rule.

## 12. Candidate gate

A REDUCE / RE-ADD pair is an E038 CANDIDATE only if:

- >= 15 REDUCE events;
- >= 8 actual RE-ADD events for A1/A2/A3;
- mean incremental tactical value > 0;
- median incremental tactical value > 0;
- stress-friction median incremental value >= 0;
- positive incremental-value rate >= 55%;
- Failure-path mean incremental value > 0;
- Mature-path median incremental value >= -0.25%;
- q25 incremental value > -1.5%.

A0 literal reuse is reported even if it has too few re-adds.
It cannot pass if fewer than 8 actual re-adds occur.

REDUCE_ONLY may be retained as a de-risk candidate only if:
- >=15 events;
- mean and median incremental tactical value >0;
- Failure-path mean >0;
- Mature-path median >= -0.25%.

## 13. Direct-close interpretation

No new full-close trigger can be accepted in E038.

The current state-based reference CLOSE remains the only full-close rule.

E038 may only flag a REDUCE event as a future CLOSE candidate if:
- full-close edge mean >0;
- full-close edge median > +0.20%;
- positive full-close edge rate >=60%.

Such a finding requires a new Experiment ID before validation.
