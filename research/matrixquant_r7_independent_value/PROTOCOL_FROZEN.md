### Hypothesis and directional target
Does each MatrixQuant module add **incremental future directional forecasting information** beyond plain OHLCV price/momentum/volatility plus SPY market regime? No searching for buy/sell thresholds. Binary labels at t: 1 iff Close[t+h] > Open[t+1], horizons h=5 and h=20 trading sessions. All features known at CLOSE(t), no forward price leakage. Rows lacking t+h are omitted. Full long-only profits are NOT a target; this is a predictive information falsification test.
Training = 2020-01-01 through 2023-11-30 on 20 prior stocks [AAPL MSFT NVDA AMD ABT JNJ AMZN GOOGL META ORCL LLY JPM BAC GS WMT PG COST XOM CAT TSLA], completely embargoing December 2023 vs 20-trading-day labels. Holdout = Jan 2024-Aug 2026 on twenty *previously unused ticker symbols* [V MA UNH ABBV MRK PFE HD LOW NKE KO PEP DIS NFLX CRM ADBE INTC CSCO BA UPS MS]; selected before any holdout responses, no replacement based on performance, label omissions if data fail. Date and ticker axes both held out; 'unseen' here means unseen to the model and these R4-R6 studies, not a truly prospective future/live holdout. Survivorship bias unavoidable (surviving liquid names).
Frozen Twelve Data 1D OHLCV from R4 training batch01/02/03. Request fresh 1D historical snapshots 2018-01-01..2026-09-30 for all new 20 symbols and SPY; save exact raw bytes to repository branch. Stock-split/dividend adjustment cannot be independently certified, which limits price predictive claims.
Only two parameter sets, fixed before inspecting holdout:
- User MODIFIED: PAI price stochastic 14, smooth SMA3, dispersion STDP(close,21), dispersion stochastic14; WT EMA10/10/21, Laguerre(g=.08) enabled, signal SMA4; Trend 13 OHLC4 vs 21 close, original precise sum/ratio expression; Gold Zone 8/8 RSI with low<30.
- Author ORIGINAL: PAI 20/SMA3, dispersion stdev20 & stochastic20; WT EMA10/10/21, Laguerre OFF, signal MA4; trend OHLC8 close20; Gold Zone8/8.
Do not modify source formulas; for zero denominators suppress invalid row. Reference values from user TDX have not been independently per-bar validated to TradingView Pine; the source's original Trend Detector unusual ratio is NOT changed.
Feature vectors determined up front:
BASE = raw close returns previous5/20 bars, historical realized standard deviation of daily returns 20 (no future), close in last20 high-low range, OHLC close location current bar, logarithm of mean volume last5 / mean volume last20, SPY market returns previous5/20.
Trend group = Trend Detector level and delta5 (raw source expression).
Gold group = Gold Zone RSI and current Gold<30 binary.
WT group = WT main, (WT main - WT signal), change in that difference since prior bar.
PAI group = PAI raw, delta1, PAIraw>40, PAIraw<-40.
Models: baseline only; BASE+each group one at a time; BASE+ALL; leave-one-out BASE+(ALL except group) (10 models per parameter version per horizon).
**Fixed estimator:** ridge-penalized logistic regression with intercept (unpenalized), global training-only standardized features, fixed L2=0.01 on average negative log likelihood (penalty on standardized non-intercept coefficients only), IRLS/Newton no hyperparameter tuning. If a training row lacks any feature skip it; test complete cases with identical row set across models of each parameter/horizon. Class labels not calibrated on test. Clamp probabilities only for stable logloss.
Metrics: mean Brier score PRIMARY (lower better), mean log loss secondary, ROC AUC optional, sign-accuracy at fixed >=0.5 threshold, number of predictions and positive prevalence. Incremental value = Brier(BASE) - Brier(BASE+group); FULL vs BASE and leave-one-out ablation check FULL vs FULL-minus-group; original vs modified separately. Difference aggregated on identical test rows (not mismatched coverage).
Robustness: report delta Brier by *each new ticker* (20 sign consistency) and early vs late test 2024-2025 vs Jan-Aug 2026; paired MONTH-based block bootstrap resampling monthly clusters 3000 times with deterministic fixed seed (captures contemporaneous cross-stock correlation; still assumes months independent, underestimates long-regime persistence). Report 95% bootstrap CI for Brier differences; numerical tolerance <1e-6 for replay; use deterministic code stored in repo; no test-set model selection.
Promotion criteria predeclared: a module qualifies only if its isolated BASE+module improves Brier vs BASE with month-block 95% CI lower >0 at BOTH 5 and 20 day horizons, improves majority of new tickers at BOTH horizons, and FULL-model ablation consistently worsens score when that module removed; **both parameter variants are independent comparisons, no post-hoc picking the better winner**. Whole four-module model qualifies only if Brier improvement over BASE robust for BOTH horizons and >0 majority stocks. Note multiple comparisons even if these tests pass; final adoption would require prospective validation and source parity.
If none passes, R7 closes status NO_PROVEN_INCREMENTAL_PREDICTIVE_VALUE; no next round of optimization, no change to 5s/SSSS/server/futu/TDX or live trading. If technical parity or invalid dataset prevents meaningful test, report inconclusive instead of false rejection.
